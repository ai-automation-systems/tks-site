ТЕНТОВЫЕ КОНСТРУКЦИИ — ЛОКАЛЬНЫЙ САЙТ С ФОТОГРАФИЯМИ

Запуск:
1. Откройте терминал в папке сайта.
2. Выполните: python3 -m http.server 4180 --bind 127.0.0.1
3. Откройте http://127.0.0.1:4180/

29 основных страниц, 26 страниц проектов, 11 недублирующихся карточек готовых ангаров.
Исходные тексты: content/source.txt.
Оформление: css/style.css. Фотомакет главной: css/home-photo.css и home_photo.py.
Фотографии: img/. Источники: content/photo-sources.json и content/all-photos.json.
Внутренние страницы: all_photos.py и css/all-photos.css.
Поведение: js/main.js.
HTML лежит по папкам страниц, сторонних библиотек и сборщика нет.
Изменения в исходном TXT можно перенести командой python3 build.py.

Фотографии производителя размещены на всех 55 содержательных страницах.
У каждого из 26 проектов своя фотогалерея. Фото увеличиваются нажатием.
Карточки готовых комплектов остались с параметрами и иконками: в исходном каталоге снимки отсутствовали.
Нет отправки заявок и вымышленных юридических документов.
Все страницы закрыты от индексации. До публикации нужно подключить формы, утверждённые документы, домен и фотографии, проверить актуальность контактов и условий.
Код организован отдельными HTML, CSS и JS файлами по аналогии с предоставленным архивом 2vlad.
